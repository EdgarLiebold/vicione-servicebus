# Security Policy

## Supported versions

This repository has no declared supported release series or security support window. Report findings
against the current `main` branch and include the affected commit. Support for a published package
must be established explicitly before it is listed here.

## Reporting a vulnerability

Report a vulnerability privately. Do not include exploit details in a public issue or discussion.

Use the [repository's private vulnerability report form](https://github.com/EdgarLiebold/vicione-servicebus/security/advisories/new),
also linked from the issue template. If the form is unavailable, contact the repository owner through
an existing private channel before sending vulnerability details.

Include the observed behavior, reproduction steps, impact, and affected commit or package version.
The maintainer will coordinate a fix and any public disclosure with the reporter in the private thread.
