# Review note for the 34 newly read C# exceptions

`remaining-csharp-source-read.tsv` binds each complete reading to the current file bytes. The set comprises 13 compilation-only global-using files, three small internal graph-validation declarations, and 18 runtime/configuration implementation files. This is a first-read and initial defect-triage record, **not** 34 A+ acceptances or a substitute for the source/API/test matrix.

The global-using files have no executable behavior. The graph declarations define the cyclic-graph exception constructors and Tarjan/topological-sort node properties; no direct contract violation was observed in those declarations. In the runtime group, the Amazon SQS host settings guard setters after freeze and reject conflicting credentials/client-factory configuration; its referenced cache-options object was checked and is immutable. The configuration notification class serializes exactly-once observer execution and rethrows a captured failure. The cache entry/key, timeout observer/proxy, circuit-breaker validation, journal observer, registration-filter, outbox identity, and correlation-ID files were examined in full; their owner-level behavior and negative/boundary test mapping remain part of the wider A+ gate.

One concrete boundary candidate needs targeted verification: `EntityNameShortener.Shorten` slices the UTF-16 input at `prefixLength` without checking whether it lands between a high and low surrogate. A supplementary Unicode character at that boundary could yield an unpaired surrogate in a generated name. `ConsumeTopology.CreateTemporaryQueueName(string tag)` accepts a caller tag, and `DefaultEndpointNameFormatter.GetTemporaryQueueName` also clips that tag by UTF-16 length. A focused test should establish the intended name-length/Unicode contract and cover both boundaries before changing either implementation. The Core-test-project owner has been notified; no test or product code was edited for this candidate yet.
